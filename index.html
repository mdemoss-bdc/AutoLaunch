How to Find Dealership Parameters

        

        
      


      

        

          

            1
            Finding the Feed URLs (Used, Certified, New)
          

          
On your dealership website, navigate to each section (Used Cars, Certified Pre-Owned, or New Inventory) and copy the clean URL from your address bar.

        


        

          

            2
            Finding the Page Modifier Pattern
          

          
Click on Page 2 of any listing view. Note how the address ends and replace the page number with {page}:

          

            
If it ends in ?pt=2 ➔ pattern is ?pt={page}

            
If it ends in ?page=2 ➔ pattern is ?page={page}

            
If it ends in /page/2/ ➔ pattern is /page/{page}/
