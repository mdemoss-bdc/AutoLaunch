Coming soon: one-click install from the Chrome Web Store

The helper is being prepared for the Chrome Web Store as an unlisted listing. Until that listing is live there is no store link — use the manual install steps below; they take a couple of minutes.

Install the helper (manual, for now)

  1. 1 Download the app files.
    Download AutoLaunch (ZIP) from GitHub
  2. 2 Unzip the download and find the luna-rebuild/extension folder inside it. That folder is the helper.
  3. 3 Open Chrome's extensions page: type chrome://extensions in Chrome's address bar and press Enter.
  4. 4 Turn on Developer mode — the switch at the top right of that page.
  5. 5 Click "Load unpacked" and select the extension folder from step 2. The "AutoLaunch Vehicle Assistant" card should appear on the extensions page.
  6. 6 Come back to this tab and hard-refresh — press Ctrl+Shift+R — then click Check again above. The refresh is what hands the helper your signed-in session.

Good to know

  • The helper works in your signed-in Chrome: stay signed in to Facebook in Chrome and keep Chrome open while it posts.
  • Marketplace vehicle posting through the helper uses a personal Facebook account — that is how Marketplace vehicle listings work.
  • In Confirm mode the helper fills everything and waits for your Publish click; in Full Auto (Settings → Automation) it publishes on its own.
